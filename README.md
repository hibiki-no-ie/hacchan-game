# はっちゃんの神経すいじゃく

同じ絵を2枚そろえる、やさしい脳トレゲームです。
ぬいぐるみ猫の「はっちゃん」が、関西のおっちゃん口調で応援してくれます。

**▶ 遊んでみる：https://hibiki-no-ie.github.io/hacchan-game/**

- かんたん（12枚）／ふつう（16枚）／むずかしい（20枚）
- 大きなカードで、スマホでも遊びやすい
- クリアすると「はっちゃん判定」と自己ベストを表示
- 登録なし・無料・広告なし
